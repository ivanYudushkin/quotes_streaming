# Описание
Проект создан для реализации процесса стриминга информации по тикерам для пользователей, которые подключаются по TCP к с ервису стриминга котировок 

## Описание объектов
### stock.rs

Структура тикера, создание нового тикера, форматирование информации о тикере для вывода

### market_simulator.rs

Приложении для симуляции торгов на бирже. Для каждого тикера рандомное число тредеров. Для каждого тикера в отдельном потоке с рандомной частотой меняются данные и отправляются на сокет для дальнейшей обработки.
Идея в том, чтобы смоделировать биржу как отдельную сущность, к которой уже подключаются другие сервисы для обработки данных с нее

### broadcaster.rs

Реализация идеи один источник(симулятор биржи) и много приемников(пользователи, которые запрашивают тикеры)
По скольку мне хотелось генерацию данных по тикерам сделать в рамках market_simulator, то мне хотелось чтобы клиенты получали данные из общего источника market_simulator, а не получали сгенерированные данные отдельно для каждого.
Данные из market_simulator приходят на 127.0.0.1:8081, но нельзя одновременно читать один сокет из разных потоков. Я долго думал как сделать что-то похожее на брокеры сообщений, где один источник, а пользователи могут подписаться на интересующие их данные.
Мне нейронка подсказала идею с static и OnceLock, получилось вроде довольно интересно.
Для каждого подписчика создается свой отдельный канал, который хранится в общем списке подписчиков. У нас получается единый поток рассылки, который принимает сообщения от market_simulator и рассылает их по подписчикам к ним в каналы. После чего уже данные с каналов парсятся и фильтруются.
В результате каждый пользователь видит данные только по тем тикерам, которые он запрашивает
Когда пользователь отключается он удаляется из подписчиков посредством retain

### quote_server.rs

Копия сервера из учебного модуля для обработки команд

### quote_user.rs

Приложение, которое обрабатывает каждое подключение, стримит в консоль котировки
Приложение отрубается, если 1 минуту нет активных подключений

# Процесс работы 

## Запуск market_simulator

`market_simulator` - Симулятор торговли бумагами из tickers.rs. Генерирует рандомное число трейдеров, рандомную регулярность сделок и измение цены по каждой бумаге

### Запуск

```bash
cargo run --bin market_simulator
```

## Запуск market_simulator

`quote_user` - Сервис по рассылке информации пользователям по нужным бумагам. Умеет работать с несколькими пользователями

### Запуск

```bash
cargo run --bin quote_user
```

## Получение информации по тикерам
### Подключение по TCP к сервису по рассылке данных по тикерам
```bash
telnet 127.0.0.1 7878
```

### Получение данных по нужным тикерам
```bash
STREAM PYPL,AAPL,ADBE
```
